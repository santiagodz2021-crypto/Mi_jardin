# Mi jardín

Archivos que hay que subir a GitHub (todos juntos, en la raíz del repositorio):
`index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`

## Publicar con GitHub Pages
1. En GitHub: **New repository** (por ejemplo `mi-jardin`), público.
2. **Add file → Upload files**, arrastra los 5 archivos y pulsa **Commit changes**.
3. **Settings → Pages**: en *Branch* elige `main` y carpeta `/ (root)`, y guarda.
4. En 1-2 minutos aparece el enlace `https://TUUSUARIO.github.io/mi-jardin/`.

## Instalar en el Android
Abrir el enlace en Chrome, menú (tres puntos) → **Instalar aplicación** o **Añadir a pantalla de inicio**.

## Cosas a saber
- Los datos se guardan solo en el móvil. Usar de vez en cuando **Guardar copia de seguridad** (abajo del todo en Casas) y guardar el archivo en un sitio seguro.
- Para cambiar de móvil: guardar la copia en el viejo y usar **Recuperar una copia** en el nuevo.
- Para actualizar la app, sube el nuevo `index.html` al repositorio (se reemplaza el anterior).
- La pestaña de asistente de IA solo existe dentro de claude.ai; aquí no aparece.
